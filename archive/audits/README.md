# Historical audit materials

- `fpr-review/`: superseded first-pass FPR review tools, queue, decisions, and backups.
- `pre-camera-ready/`: older statistical narrative/dossier, raw-data audit,
  example reports, and report-generation scripts.

These files are preserved verbatim and may contain superseded interpretations
or references to their original paths. They are provenance records rather than
current reproduction entry points. Use the submission tag for historical replay.

The current [audit directory](../../paper/audit/README.md) retains the final
numerical analyses, queue, human decisions, per-case findings, and usage ledger.
Running the paired analysis writes its legacy narrative to ignored
`tmp/analysis/paired_audit_summary.md`; it does not replace these archived files.
