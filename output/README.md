# Preserved submission artifacts

`pdf/` contains the exact submitted camera-ready paper and its final yellow-only
comparison. `release/` contains the corresponding source/reproducibility ZIPs,
release manifest, and production verification record.

These files are frozen at tag `camera-ready-submitted-2026-09-12` (`ab9cfba`).
The [submission record](../docs/submission.md) identifies them and their hashes.
Current build commands write rebuilt PDFs to `tmp/pdfs/` and packages to
`tmp/release/`, leaving these originals untouched. Intermediate review PDFs are
preserved in [archive/camera-ready/pdf](../archive/camera-ready/pdf/).
